## Getting Started

This portfolio uses Create React App under the hood.

Prerequisites:
```
node@v10.16.0 or higher
npm@6.9.0 or higher
git@2.17.1 or higher
```

Setup:
```bash
# Clone your repository
git clone <your-repo-url>
cd developerFolio

# Copy env example
cp env.example .env

# Install dependencies
npm install

# Start the dev server
npm start
```

## Configuration

Personalize page content in src/portfolio.js and update public/index.html metadata for accurate SEO.

GitHub data (optional):
```env
REACT_APP_GITHUB_TOKEN="YOUR_GITHUB_TOKEN"  # keep secret; do not commit
GITHUB_USERNAME="JuniorDCoder"
USE_GITHUB_DATA="true"
```

Medium blogs (optional):
```env
MEDIUM_USERNAME="foryoungjuniorngu"
```

Note: Treat tokens like passwords. Do not hardcode secrets; use environment variables and ensure .gitignore includes .env.

## Deployment
- GitHub Pages: follow CRA docs — https://create-react-app.dev/docs/deployment/#github-pages
- Netlify/Vercel: connect the repo and deploy; build command `npm run build`, publish `build/`
- Custom domain: add CNAME in public/
